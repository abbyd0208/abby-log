# 兩欄版型佈局原型

本檔案描述現有版型 vs 新版型的結構對比。

---

## 現有版型（單欄）

```
┌─────────────────────────────────────────────────┐
│                    HEADER                        │
│  標題、日期、摘要、標籤                            │
└─────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────┐
│ TOC（目錄框，rounded-xl）                        │
│ • 目錄標題 1                                     │
│   - 目錄標題 1.1                                 │
│ • 目錄標題 2                                     │
└─────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────┐
│                                                  │
│  文章內文（17px, prose-log）                    │
│  • 段落 1                                        │
│  • 段落 2                                        │
│  • ...                                          │
│                                                  │
└─────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────┐
│         前一篇 | 後一篇（導航）                    │
└─────────────────────────────────────────────────┘

【問題】
- 閱讀時需要往上翻找 TOC，頻繁切換焦點
- TOC 和內文無視覺分離
- 單欄擠壓感
```

## 新版型（兩欄 + Sticky TOC）

### 版型 A / C（標準兩欄）

```
┌────────────────────────────────────────────────────┐
│                    HEADER                          │
│  標題、日期、摘要、標籤                               │
└────────────────────────────────────────────────────┘
                           ↓
┌──────────────┬──────────────────────────────────┐
│              │                                  │
│  LEFT COL    │      MAIN CONTENT (RIGHT)        │
│  TOC         │                                  │
│              │  文章標題                          │
│ ┌──────────┐ │  ==================              │
│ │ 目錄     │ │                                  │
│ │ • 標題 1 │ │  第一段內容...                     │
│ │  - 1.1   │ │                                  │
│ │  - 1.2   │ │  ## 小標題                        │
│ │ • 標題 2 │ │  內容...                          │
│ │  - 2.1   │ │                                  │
│ │ • 標題 3 │ │  ## 另一小標題                      │
│ └──────────┘ │  內容...                          │
│              │                                  │
│ (sticky)     │  ...（更多內容）                   │
│ (top: 100px) │                                  │
│              │                                  │
└──────────────┴──────────────────────────────────┘
                           ↓
┌────────────────────────────────────────────────────┐
│              前一篇 | 後一篇（導航）                  │
└────────────────────────────────────────────────────┘

【優點】
✅ TOC 始終可見（sticky）
✅ 兩欄視覺清晰，層級分離
✅ 閱讀時無需往上翻
✅ 導航用戶體驗提升 ↑↑
```

### 版型 B（寬 TOC，強調層級）

```
┌────────────────────────────────────────────────────┐
│                    HEADER                          │
│  標題、日期、摘要、標籤                               │
└────────────────────────────────────────────────────┘
                           ↓
┌──────────────────┬────────────────────────────┐
│                  │                            │
│  LEFT COL        │      MAIN CONTENT          │
│  TOC (260px)     │  (max-width: 720px)        │
│                  │                            │
│ ┌──────────────┐ │  文章標題                    │
│ │ 目錄         │ │  ==================        │
│ │ • 標題 1     │ │                            │
│ │   - 標題 1.1 │ │  第一段內容...               │
│ │   - 標題 1.2 │ │                            │
│ │   - 標題 1.3 │ │  ## 小標題                  │
│ │ • 標題 2     │ │  內容...                    │
│ │   - 標題 2.1 │ │                            │
│ │ • 標題 3     │ │  ## 另一小標題                │
│ │   - 標題 3.1 │ │  內容...                    │
│ │   - 標題 3.2 │ │                            │
│ │   - 標題 3.3 │ │  ...（更多內容）             │
│ └──────────────┘ │                            │
│                  │                            │
│ (sticky)         │                            │
│ (top: 100px)     │                            │
│                  │                            │
└──────────────────┴────────────────────────────┘
                           ↓
┌────────────────────────────────────────────────────┐
│              前一篇 | 後一篇（導航）                  │
└────────────────────────────────────────────────────┘

【特色】
✨ TOC 寬度更大（260px），容納更多層級縮進
✨ 內文設置 max-width: 720px，提高可讀性
✨ 層級縮進 12px（而不是 4px），視覺層級更清晰
```

## 斷點適應（響應式）

### 平板 (768px 以上)
- 保持兩欄版型
- TOC sticky 生效
- 正常顯示

### 手機 (< 768px)
- 堆疊版型（TOC 在上，內文在下）
- TOC 不 sticky（避免遮擋內容）
- TOC → Accordion/Collapsible（可選）

```
┌──────────────────┐
│     HEADER       │
└──────────────────┘
         ↓
┌──────────────────┐
│  TOC（Collapse） │
│  ⊕ 目錄          │
└──────────────────┘
         ↓
┌──────────────────┐
│  內文 full-width │
│  ...             │
└──────────────────┘
```

## 代碼結構變化

### 現有結構（[slug]/page.tsx）
```tsx
<article>
  <header>...</header>
  <Toc />
  <div>
    <Mdx />
  </div>
  <nav>...</nav>
</article>
```

### 新結構（[slug]/page.tsx）
```tsx
<article className="grid grid-cols-[240px_1fr] gap-8 md:grid-cols-1">
  <header className="col-span-2 md:col-span-1">...</header>
  
  <aside className="sticky top-24">
    <Toc />
  </aside>
  
  <main>
    <div className="prose-log">
      <Mdx />
    </div>
  </main>
  
  <nav className="col-span-2 md:col-span-1">...</nav>
</article>
```
