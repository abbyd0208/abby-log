## 第二輪修改

### 1. 新增核心 SVG 圖

新增：

`public/images/ai-agent-autonomy-levels/01.svg`

插入位置：

「三層自主度」段落後。

圖主題：

`AI 自主度 = 驗收點往後移多少`

圖中呈現：

- Level 1：我看每一步
- Level 2：我看關鍵點
- Level 3：我只看結果

並補圖說：

> 自主度不是 AI 自己升級，是我把驗收點往後移。但前提是：移到後面，我還是看得出來它有沒有做錯。

新增 markdown 模板：

```md

- 下一步應該是什麼：
```

> 以上感謝收看～ 如果你也在調自己的多 agent 分工，歡迎留言聊聊你把驗收點放在哪一段。
