## 🎯 上傳步驟

### 對每篇文章：

1. **開啟 Medium 編輯器**
   - 前往: https://medium.com/new-story

2. **複製標題**
   - 打開對應的 markdown 檔案
   - 複製標題（檔案頂部 `#` 後的文字）
   - 貼入 Medium 的標題欄位

3. **填寫摘要**
   - 複製 markdown 檔案中的 `**Summary:**` 行
   - 貼入 Medium 的預覽欄位

4. **新增標籤**
   - 複製 markdown 檔案中的標籤（逗號分隔）
   - 逐個加入 Medium（每個標籤後按 Enter）

5. **複製內容**
   - 複製 `## CONTENT` 之後的所有內容
   - 貼入 Medium 編輯器

6. **上傳圖片**（如果有）
   - 點擊 Medium 編輯器的圖片圖示
   - 從 markdown 檔案指定的路徑上傳各張圖片

7. **儲存為草稿**
   - **⚠️ 重要**: 絕對不要發佈
   - 點擊三點菜單
   - 選擇「Save as draft」
   - **NOT** 「Publish」

8. **記錄草稿連結**
   - 儲存後，從瀏覽器位址欄複製 URL
   - 這就是你的草稿連結
