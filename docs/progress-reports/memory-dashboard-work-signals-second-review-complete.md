目的：讓文章和前文形成互聯，也讓沒背景讀者能回去看前情。

### 2. 新增匿名化 dashboard 表格

- recent
- idle
- next

目的：補足第一輪讀者指出的「文章一直講 dashboard，但沒有 dashboard 畫面」。

### 3. 新增 before / after 例子

新增：

```text
模糊 recent：

可接續 recent：
已整理三版首頁資訊架構，卡在「搜尋結果是否獨立成頁」，下一步等我確認方向。
```

目的：讓「可接續狀態」從抽象概念變成可複製寫法。

### 4. 修掉泛用結尾

刪除原本固定簽名段，只保留貼近本文的行動呼籲：
