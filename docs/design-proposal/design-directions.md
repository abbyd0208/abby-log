# 設計方案 v1：3 種方向提案

**日期：** 2026-08-03  
**基於：** Abby-log 現有設計分析 + 行業最佳實踐（Linear、Vercel、Stripe、Notion）

---

## 方案 A：現代清爽型 🌈

### 視覺目標
降低視覺複雜度，強調可讀性和現代感。適合內容驅動的部落格。

### 色系方案
```
主色：從 #2f6fd6 → #1e5ba8（更深、更沉穩的藍）
輔色：從 #1aa06a → #16a34a（Stripe 綠，更柔和）
點色：從 #e0700d → #d97706（Amber，更溫暖）

背景：#ffffff（保持白底）
文字：#1a1a1a（從 #37352f 更深）
邊框：#e5e7eb（更淡的灰，提高負空間感）
引用背景：#f9fafb（接近白色的灰）
```

### 排版改進
```
h1: 36px → 40px（+4px，更有氣勢）
h2: 24px → 28px（+4px）
h3: 19px → 22px（+3px，層級對比 ↑）
body: 17px → 18px（+1px，現代風格）
line-height: 1.85 → 1.8（緊湊感 ↓，負空間 ↑）
letter-spacing: -0.02em（保持）
```

### 版型改進（兩欄版型）
```
文章頁結構：
┌─────────────────────────────────┐
│ Header（標題 + 日期 + 標籤）     │
└─────────────────┬───────────────┘
                  │
        ┌─────────┴────────┐
        │                  │
   左欄（TOC）          右欄（內文）
   寬度：240px         寬度：calc(100% - 240px - 32px)
   sticky: top         
   position: sticky    
   top: 100px          
        │                  │
        └─────────────┬────┘
                      │
        ┌─────────────┴─────────────┐
        │  底部導航（前一篇/後一篇）│
        └───────────────────────────┘
```

### 優點 ✅
- 現代、輕盈感強
- TOC 視覺層級提高（固定側欄）
- 兩欄版型更清晰
- 色系柔和但專業

### 實現難度
⭐⭐ 中等（需要修改 [slug]/page.tsx 版型 + globals.css 色系）

## 方案 B：學術沉靜型 📖

### 視覺目標
強調學術嚴謹感和排版層級感。適合深度內容。參考 Stripe Docs、Notion。

### 色系方案
```
主色：#374151（深灰，當前 #2f6fd6 改為沉靜灰）
強調色：#2563eb（藍，用於鏈接和重點）
成功色：#10b981（綠，保留 memory 系列感）

背景：#ffffff
文字：#111827（極深灰黑）
次文本：#6b7280（中灰）
邊框：#d1d5db（淡灰）
代碼背景：#f3f4f6（偏灰的淡色）

TOC 背景：#fafbfc（帶微弱藍偏色的白）
```

### 排版改進
```
h1: 36px → 48px（++12px，大幅提升視覺權重）
h2: 24px → 32px（++8px，層級對比 ↑↑）
h3: 19px → 24px（++5px）
body: 17px → 16.5px（保留舒適性）
line-height: 1.85 → 1.7（視覺層級更清晰）
letter-spacing h2: -0.02em → -0.03em（更緊湊）
```

### 版型改進
```
左欄 TOC：260px（比 A 方案更寬，容納更多層級）
右欄內文：calc(100% - 260px - 48px)
內文最大寬度：720px（經典文章寬度）
TOC font-size：14px（A 方案是 13.5px，增加易讀性）
TOC 層級縮進：8px → 12px（更清晰的層級感）
```

### 特殊細節
- h2 底部加 border-bottom（淡灰線）做視覺分隔
- blockquote 左邊框顏色：淡灰 → 強調色
- TOC 當前項目高亮：背景色 + 強調色文字

### 優點 ✅
- 層級感最強（標題尺寸差異大）
- 學術/專業感十足
- TOC 作為可靠的導航錨點
- 色系中性、不會過時

### 實現難度
⭐⭐⭐ 中-高（需要調整多處排版細節 + h2 特殊樣式）

## 方案 C：原色系優化型 🎨

### 視覺目標
保留 Abby-log 現有的「靈魂色」#2f6fd6（藍） / #1aa06a（綠） / #e0700d（橙），但優化排版和版型。最小化重構。

### 色系方案
```
soul: #2f6fd6 → #2563eb（保留系列，稍微調淡一點點）
memory: #1aa06a → #059669（保留綠色家族，更飽和）
user: #e0700d → #ea580c（保留橙色，更平衡）

背景保持：#ffffff
邊框調整：#e5e7eb（#eceae7 → 更淡）
文字保持：#37352f
```

### 排版改進
```
h1: 36px → 38px（微調）
h2: 24px → 26px（+2px，保留原風格但提升層級）
h3: 19px → 21px（+2px）
body: 17px（保持）
line-height: 1.85 → 1.8（微調，減少過密感）
```

### 版型改進（兩欄版型）
```
左欄 TOC：240px（同 A 方案）
右欄內文：calc(100% - 240px - 32px)
TOC 樣式：保留現有 rounded-xl border，但背景色改為 --soul-bg（#eaf1fc）
TOC 字號：保持 13.5px（保留原有風格）
```

### 優點 ✅
- 保留 Abby-log 靈魂色彩
- 重構最小化（易於快速上線）
- 風格一致性最高
- 兩欄版型提升信息層級

### 實現難度
⭐ 低（主要改 globals.css 色值 + [slug]/page.tsx 版型）
